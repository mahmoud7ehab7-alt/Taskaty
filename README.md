# 📝 تطبيق تاسكاتي (Taskaty / my_tasks)

تطبيق متكامل لإدارة المهام اليومية وتتبع الإنتاجية والتوازن الشخصي، مبني باستخدام إطار العمل **Flutter** مع دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (RTL)، والمزامنة السحابية عبر **Firebase** مع دعم العمل بدون إنترنت (Offline-First).

---

## 🌟 الميزات الرئيسية

### 📋 إدارة المهام الشاملة
- **إنشاء وتعديل المهام**: إضافة مهام جديدة مع وصف تفصيلي وتاريخ محدد.
- **مستويات الأولوية**: تصنيف المهام إلى (عالية 🔥، متوسطة ⚡، منخفضة 🌱).
- **التصنيفات والمجالات**: تنظيم المهام حسب المجالات (عمل 💼، دراسة 📚، صحة 🏃‍♂️، شخصي 👤، عام 📌).
- **المهام الفرعية (Subtasks)**: دعم إضافة مهام فرعية داخل المهمة الرئيسية مع إمكانية تحديد وقت مخصص لكل مهمة فرعية وحساب نسبة التقدم تلقائياً.
- **فترات التنفيذ (Time Windows & Slots)**: إمكانية تحديد أوقات بداية ونهاية محددة أو إضافة فترات زمنية متعددة للعمل على المهمة.
- **الوقت الفعلي مقابل المخطط**: إدخال الوقت المستغرق الفعلي عند إكمال المهمة ومقارنته بالوقت المخطط لمعرفة الوقت الموفر أو الإضافي (مثال: "وفرت 15 دقيقة ⚡").

### 📊 مؤشر وتحليلات الإنتاجية
- **عداد الإنتاجية التفاعلي (Productivity Gauge)**: حساب معدل الإنتاجية اليومي والأسبوعي والشهري بناءً على الساعات المخططة والمقضية فعلياً.
- **تتبع سلسلة الالتزام (Streak Engine)**: حساب عدد الأيام المتتالية المكتملة بنجاح مع عرض أفضل رقم قياسي تم تحقيقه.
- **رسم بياني لأداء 7 أيام**: عرض تفصيلي لإنجازات الأيام السبعة الأخيرة.
- **تحليلات حسب التصنيف**: إمكانية استعراض الإنتاجية لكل مجال أو تصنيف بشكل منفصل.

### 🔐 الحسابات والمزامنة السحابية
- **تسجيل الدخول عبر Firebase Auth**: إنشاء حساب جديد أو تسجيل الدخول بالبريد الإلكتروني وكلمة المرور.
- **الدخول كضيف (Guest Login)**: إمكانية استخدام التطبيق فوراً كضيف دون الحاجة للتسجيل.
- **المزامنة مع Cloud Firestore**: مزامنة المهام والبيانات فورياً عبر السحاب.
- **التخزين المحلي والعمل أوفلاين (Offline-First)**: الاعتماد على `SharedPreferences` لتخزين البيانات محلياً واسترجاعها فوراً حتى عند عدم توفر اتصال بالإنترنت.
- **أمان الحسابات المحلية**: تشفير كلمات المرور محلياً باستخدام خوارزمية `SHA-256` مع حبات الملح (`Salt`) وحماية من محاولات التخمين المكررة.

### 📤 تصدير ومشاركة التقارير
- **توليد تقارير نصية**: إنشاء تقارير إنتاجية تفصيلية (يومية، أسبوعية، شهرية) تتضمن ملخص الساعات والمهام وتفاصيل الإنجاز.
- **المشاركة**: مشاركة التقارير عبر تطبيقات التواصل الاجتماعي باستخدام حزمة `share_plus`.

### 🎨 الواجهة والتصميم
- **تصميم Material 3**: واجهة حديثة ومريحة تعتمد على درجتين من اللون التيفاني (Rich Teal `#0D9488`).
- **الوضع النهاري والداكن (Light & Dark Theme)**: تبديل سلس وسريع بين الثيم الفاتح والداكن.
- **تنسيق عربي أصيل**: استخدام مكتبة `intl` لتنسيق التواريخ والأوقات والأرقام باللغة العربية.

## 💻 متطلبات وطريقة التشغيل

### المتطلبات الأساسية
- مثبت [Flutter SDK](https://docs.flutter.dev/get-started/install) (الإصدار 3.29.0 أو أحدث).
- بيئة تطوير مثل VS Code أو Android Studio.

### خطوات التشغيل المحلي

1. **استنساخ المستودع (Clone)**:
   ```bash
   git clone <repository-url>
   cd my_tasks
   ```

2. **تثبيت حزم Dart و Flutter**:
   ```bash
   flutter pub get
   ```

3. **تشغيل التطبيق**:
   ```bash
   flutter run
   ```

## 🖥️ البناء والتشغيل لمنصتي ويندوز والويب (Windows & Web)

يتضمن المشروع أدوات وسكريبتات مساعدة جاهزة للبناء والتثبيت المباشر:

- **البناء لمنصة Windows**:
  يمكن استخدام سكريبت `install_and_build.bat` لبناء النسخة التنفيذية (`Release`) تلقائياً مع تثبيت أدوات Visual Studio C++ إذا لزم الأمر وإنشاء اختصار للتطبيق على سطح المكتب:
  ```cmd
  install_and_build.bat
  ```

- **التشغيل على الويب (Standalone Web App)**:
  يتضمن المشروع خادم Node.js خفيف `desktop_runner.js` لتشغيل نسخة الويب محلياً:
  ```bash
  node desktop_runner.js
  ```
